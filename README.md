# 🍔 Food Ordering System

A console-based **Food Ordering System developed in C** that allows users to browse food items, place orders, calculate totals, and manage their selections through an interactive command-line interface.

## 📌 Overview

The Food Ordering System simulates a basic restaurant ordering process. Users can select food items, specify quantities, review their orders, and calculate the final bill using structured C programming and menu-driven logic.

## ✨ Features

* Interactive food menu
* Food item selection
* Quantity management
* Order processing
* Automatic bill calculation
* Order summary
* User input validation
* Menu-driven interface

## 🛠️ Technologies Used

* **C Programming**
* **Standard C Libraries**
* **C Header File**
* **Console / Command-Line Interface**

## 🎯 Concepts Demonstrated

* Variables and data types
* Conditional statements
* Loops
* Functions
* Arrays
* Structures
* User input handling
* Menu-driven programming
* Data processing and calculations

## 🚀 Purpose

This project was developed to apply fundamental C programming concepts to a practical real-world scenario while gaining experience in designing structured, menu-driven applications.
